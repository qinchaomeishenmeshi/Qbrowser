
# 多开浏览器管理软件产品设计需求说明书

---

## 一、项目概述

### 1.1 产品定位

- **名称**：QW-Browser浏览器管理工具
- **类型**：跨平台桌面应用（Windows/macOS/Linux）
- **目标用户**：短视频创作者、电商运营人员、需要同时管理多个独立浏览器环境的技术人员
- **核心价值**：实现多浏览器实例的快速创建、隔离管理与Cookie/Headers资源管理

---

## 二、用户场景

| 场景类型 | 典型用例 |
|----------|----------|
| 多账号操作 | 同时登录多个电商平台账号（如巴营）进行内容管理 |
| 环境隔离 | 每个浏览器实例与用户ID绑定，独立管理cookie和会话信息 |
| 数据采集 | 自动化收集多个账号的cookies和headers信息用于API调用 |
| 远程控制 | 通过API接口远程管理浏览器实例，支持浏览器操作自动化 |

---

## 三、功能需求

### 3.1 核心功能模块

| 模块名称       | 功能描述                                                                 |
|----------------|--------------------------------------------------------------------------|
| 实例管理       | 创建/启动/停止/批量管理浏览器实例，每个实例关联唯一用户ID               |
| Cookie管理     | 自动收集和管理多个用户的cookies和headers信息，支持全量数据采集           |
| 网络服务       | 提供FastAPI服务，允许通过HTTP接口远程控制浏览器行为                      |
| 内网穿透       | 集成frpc服务（Windows），支持远程访问本地浏览器                          |
| 数据持久化     | 保存用户配置、端口映射和会话信息，支持应用重启后恢复                     |

---

## 四、界面设计

### 4.1 整体布局

```plaintext
+--------------------------------------+
| [启动浏览器] [一键关闭] [加载] [清除] | ← 顶部操作栏
+--------------------------------------+
| [文本输入区域：user_ids]             | ← 用户ID输入区
+--------------------------------------+
| [进度条]                             | ← 操作进度
+--------------------------------------+
| [日志显示区域]                       | ← 实时操作日志
+--------------------------------------+
```

### 4.2 关键页面设计

#### 4.2.1 主界面

- **输入区域**：
    - 多行文本框，每行一个user_id
    - 支持直接输入或从文件加载
- **操作按钮**：
    - 启动浏览器：绿色按钮，启动所有输入的user_id对应的浏览器实例
    - 一键关闭：红色按钮，关闭所有运行中的浏览器实例
    - 加载user_ids.txt：蓝色按钮，从文件加载用户ID列表
    - 清除缓存：橙色按钮，清除浏览器数据和配置缓存
- **进度显示**：
    - 进度条显示批量操作的完成进度
- **日志区域**：
    - 实时显示操作日志，自动滚动到最新记录

## 六、技术需求

### 6.1 核心技术栈

| 技术类别 | 具体实现 |
|--------|-----------------|
| GUI框架 | PyQt6 |
| 浏览器自动化 | DrissionPage |
| API服务 | FastAPI + uvicorn |
| 异步支持 | qasync + asyncio |
| 网络请求 | httpx/requests |
| 内网穿透 | frpc (Windows) |

### 6.2 数据管理

| 数据类型 | 存储方式 |
|--------|----------|
| 用户ID缓存 | JSON文件 (user_ids_cache.json) |
| 端口映射 | JSON文件 (user_ports_cache.json) |
| Cookies | 本地文件目录 (data/cookies/) |
| 浏览器数据 | 本地隔离目录 (browser_data/{user_id}/) |

### 6.3 浏览器实例配置

- **浏览器内核**：Chromium
- **用户数据目录**：独立目录保存每个用户的浏览器配置
- **端口分配**：动态分配 (9000-10000)
- **扩展插件**：支持加载自定义Chrome扩展

### 6.4 系统要求

- **操作系统**：Windows 10+/macOS/Linux
- **Python版本**：3.8+
- **特殊权限**：Windows下使用管理员权限可获得更好体验

## 七、API服务

### 7.1 主要API端点

| 端点 | 方法 | 功能描述 |
|------|------|----------|
| `/status` | GET | 获取运行状态和用户数量 |
| `/start/{user_id}` | POST | 启动特定用户的浏览器实例 |
| `/stop` | POST | 停止所有浏览器实例 |
| `/start_all` | POST | 批量启动多个用户的浏览器实例 |
| `/anchor_coupon/create` | POST | 业务接口：创建优惠券 |

### 7.2 数据收集能力

- **全量数据收集**：收集所有cookies和headers信息
- **监听API**：支持监听特定API路径获取headers信息
- **数据持久化**：按用户ID和站点分类存储数据
