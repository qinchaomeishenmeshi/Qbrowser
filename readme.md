### 1.0 版本指南

1. **创建虚拟环境**
   ```bash
   python -m venv myenv
   ```


2. **激活虚拟环境**
    - Windows:
      ```bash
      .\myenv\Scripts\activate
      ```

    - macOS/Linux:
      ```bash
      source myenv/bin/activate
      ```


3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```


4. **配置浏览器实例编号**
    - 打开 `user_ids.txt` 文件，修改需要打开的浏览器实例编号。根据需求调整实例数量。

5. **运行程序**
   ```bash
   python app2.py
   ```
